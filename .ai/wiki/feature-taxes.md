# 💰 Фіча "Податки" (:feature:taxes)

## 📌 Огляд фічі

Модуль `:feature:taxes` розроблений для повноцінного обліку доходів та з нарахованих по ним податків. Всі доходи кешуються локально в DataStore та поділяються на два види:
1. **Неоподатковані доходи**: занесені користувачем доходи, по яким ще не запускався розрахунок податку.
2. **Оподатковані доходи**: доходи, по яким було виконано розрахунок податку (зі збереженням конкретного курсу НБУ на дату доходу, суми в UAH, єдиного податку, військового збору та ЄСВ).

---

## 🏗️ Структура модуля `:feature:taxes`

Модуль розділений на два окремих екрани, кожен із власним ViewModel:

1. **Головний екран "Податки"**:
   - **`TaxesScreen.kt`**:
     - **Контейнер неоподаткованих доходів** (`OutlinedCard`): відображається зверху (над формою додавання) за наявності неоподаткованих доходів (`state.untaxedIncomes.isNotEmpty()`). Кожен елемент `IncomeItemRow` відображає дату, суму у валюті та еквівалент у гривнях (`amountUah`).
     - **Форма додавання доходу** (`OutlinedCard`): дата, сума, вибір валюти та кнопка "Додати дохід".
     - **Кнопка "Розрахувати податок"** (`AppButton`): розміщується під формою додавання доходу за наявності неоподаткованих доходів.
     - **Шторка результатів розрахунку** (`ConfirmBottomSheet` із заголовком "Неоплачені податки"): з'являється після проведення розрахунку (`state.calculationResult != null`) із вмістом `ResultCard` та кнопками "Оплатити" й "Скасувати".
     - **Автопрокрутка**: за допомогою `LaunchedEffect(state.untaxedIncomes.size)` головний контейнер `Column` плавно скролиться до кінця (`scrollState.animateScrollTo(scrollState.maxValue)`) при додаванні кожного нового доходу.
   - **`TaxesViewModel.kt`**: Управляє додаванням нових доходів, валідацією полів, розрахунком податку за курсом НБУ та збереженням результатів розрахунку `TaxCalculation`.

2. **Екран "Історія податків"**:
   - **`TaxesHistoryScreen.kt`**: Окремий екран історії з ідентичним візуальним стилем карт до `HistoryScreen`. Відображає перелік усіх закешованих доходів із плашками статусу ("Оподатковано" / "Не оподатковано"), чекбоксами вибору доходів, та кнопками группових дій ("Оплатити" та "Видалити" вибрані елементи із підтвердженням у `ConfirmBottomSheet`).
   - **`TaxesHistoryViewModel.kt`**: Окремий ViewModel, який відповідає за спостереження списку доходів, вибір доходів чекбоксами, масове видалення обраних елементів та обчислення загальної суми до сплати для обраних доходів.

3. **DI Конфігурація**:
   - **`di/Module.kt`**: Реєструє обидві ViewModel у Koin-модулі `featureTaxesModule()`.

## 🔄 Логіка роботи та корисні сценарії

### 1. Додавання та динамічний/онлайн розрахунок курсів
Користувач заповнює дату доходу (за замовчуванням сьогоднішня), суму та валюту (UAH, USD, EUR, PLN тощо).
При натисканні кнопки **"Додати дохід"**:
1. Валідуються введені дані (відсутність майбутніх дат, позитивна сума).
2. `TaxesUseCase.addIncome()` додає запис до кешу.
3. При завантаженні та спостереженні за доходами через `TaxesUseCase.getIncomes()`, для будь-яких неоподаткованих доходів у яких `amountUah == 0.0` (наприклад, внесених раніше або в офлайн-режимі), запитується актуальний курс НБУ онлайн і розраховується `amountUah`.
4. Оновлені курси та суми в UAH автоматично зберігаються в кеші DataStore, тому еквівалент у гривнях завжди відображається коректно.

### 2. Розрахунок податку для неоподаткованих доходів
Коли є неоподатковані доходи, зверху над формою додавання відображається картка зі списком неоподаткованих доходів, а під формою показується кнопка **"Розрахувати податок"**.
При натисканні кнопки "Розрахувати податок":
1. `TaxesUseCase.calculateTaxesForUnpaid(group)` знаходить всі записи з `isTaxCalculated == false`.
2. Для кожного запису розраховує єдиний податок (5% або 3% від UAH доходу для Group 3, або фіксовану ставку для Group 1-2), військовий збір (1% або фіксовану суму) та ЄСВ.
3. Оновлює об'єкти `TaxIncomeItem`: встановлює `isTaxCalculated = true` та зберігає розраховані значення податків.
4. Оновлені дані зберігаються у DataStore cache.
5. Відкривається `ConfirmBottomSheet` із заголовком **"Неоплачені податки"**, що містить `ResultCard` із деталізацією розрахованих податків, а також дві кнопки: **"Оплатити"** та **"Скасувати"**.

### 3. Перегляд історії податків та оплата/видалення
При натисканні на кнопку з іконкою **"Історія податків"** у верхній панелі (TopAppBar):
1. Відбувається переход на новий екран `AppScreen.TaxesHistory` (`TaxesHistoryScreen`).
2. Перемикач теми/мови в TopAppBar відсутній (TopAppBar містить лише кнопку "Назад" та заголовок).
3. Відображається список доходів у вигляді стилізованих карт `Card` з фоном як у `HistoryScreen`, де під сумою та датою розташовані плашки статусу `TaxStatusChip`:
   - 🔵 **Не оплачено** (`isTaxCalculated = true`): відображає курс НБУ, еквівалент у UAH та загальну суму нарахованих податків.
   - 🔴 **Не оподатковано** (`isTaxCalculated = false`).
4. Вибір елементів виконується кліком по картці (стан вибору відображається іконкою галочки `Icons.Default.Check` у правому верхньому куті картки); видалення обраних елементів виконується через іконку кошика у верхній панелі (`TopAppBar`) з підтвердженням у `ConfirmBottomSheet`.
5. У нижній панелі (`bottomBar`) відображаються кнопки дій:
   - **Без вибору елементів**: відображається кнопка **"Розрахувати неоподатковані"** (якщо в історії є неоподатковані доходи) та під нею кнопка **"Оплатити неоплачені"** (якщо є неоплачені податки).
   - **При виборі елементів чекбоксами**: якщо серед вибраних є хоча б один неоподаткований дохід — відображається тільки кнопка **"Розрахувати податки (X)"**; якщо всі вибрані є неоплаченими — відображається тільки кнопка **"Оплатити податки (X)"**.
   - При натисканні на кнопку оплати або розрахунку відкривається `ConfirmBottomSheet` із заголовком **"Неоплачені податки"** та вмістом `ResultCard`, де під час підтвердження закривається діалог та виконується підтвердження оплати.

## 🛠️ Взаємодіючі класи домену (`core:domen`)

- **`TaxIncomeItem`**:
  ```kotlin
  @Serializable
  data class TaxIncomeItem(
      val id: String,
      val dateString: String,
      val amount: Double,
      val currencyCode: String,
      val isTaxCalculated: Boolean = false,
      val rate: Double = 0.0,
      val amountUah: Double = 0.0,
      val singleTax: Double = 0.0,
      val militaryLevy: Double = 0.0,
      val esv: Double = 0.0,
      val totalTax: Double = 0.0,
      val groupId: String = FopGroup.GROUP_3_5.id,
      val calculatedAt: Long = 0L,
  )
  ```
- **`TaxesUseCase`**: Управляє додаванням, видаленням, розрахунком та підсумками для сплати.
